# macOS 桌面主题

奶龙主题的 macOS 主题包。苹果管得严（SIP 保护），不让随便换主题，所以本目录只提供安全可逆的配置，乖，别硬来：

- 外观设置指南（强调色、外观模式、壁纸建议）

## 目录说明

```
themes/macos/
├── setup-guide.md   # 外观设置指南
└── README.md
```

> macOS 壁纸包（深浅色各一套）、屏保图片：规划中，画饼但未上桌。
> 先用 `wallpapers/fullhd/` 的壁纸顶一顶，一样香。

## 快速开始

按 [`setup-guide.md`](setup-guide.md) 设置奶龙绿强调色和深色外观即可，全部系统原生设置，安全可逆。

## 说明

- macOS 不建议修改系统级主题文件（SIP 保护），本包以安全可逆的方式提供主题体验
