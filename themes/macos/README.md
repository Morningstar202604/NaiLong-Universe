# macOS 桌面主题

奶龙主题的 macOS 主题包。苹果管得严（SIP 保护），不让随便换主题，所以本目录只提供安全可逆的配置，乖，别硬来：

- 壁纸包（深浅色模式各一套）
- 强调色与系统外观建议（设置指南）
- 屏保图片（可选）

## 目录说明

```
themes/macos/
├── wallpapers/
│   ├── light/       # 浅色模式壁纸
│   └── dark/        # 深色模式壁纸
├── screensaver/     # 屏保图片（可选）
└── setup-guide.md   # 外观设置指南
```

## 安装步骤

### 1. 壁纸

1. 打开"系统设置 -> 壁纸"
2. 将 `wallpapers/light/` 和 `wallpapers/dark/` 拖入窗口
3. 开启"自动切换"即可随深浅色模式自动更换

### 2. 强调色

按 `setup-guide.md` 中的奶龙主题色（绿色系）设置强调色，并选择对应的深浅色外观。

### 3. 屏保（可选）

将 `screensaver/` 图片加入"系统设置 -> 屏幕保护程序"。

## 说明

- macOS 不建议修改系统级主题文件（SIP 保护），本包以安全可逆的方式提供主题体验
