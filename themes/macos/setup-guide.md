# macOS 外观设置指南

按照以下步骤，把系统外观调成奶龙主题风格。所有操作都是系统原生设置，安全可逆。

## 1. 壁纸

1. 打开"系统设置 -> 壁纸"
2. 将 `wallpapers/light/` 和 `wallpapers/dark/` 中的图片拖入壁纸窗口
3. 点击"自动切换"，系统会随深浅色模式自动换壁纸

## 2. 外观模式

打开"系统设置 -> 外观"：

- 外观：深色（配合深色壁纸）或 自动
- 强调色：选择奶龙绿系色（如绿色）
- 原色：选择"彩色"或与强调色一致

## 3. 桌面图标与小组件（可选）

- 在"系统设置 -> 桌面与程序坞"中调整图标大小，让壁纸中的奶龙更完整地展示
- 可添加时钟/天气小组件，配色选择透明深色风格，与壁纸融合

## 4. 屏保

打开"系统设置 -> 屏幕保护程序"，将 `screensaver/` 中的图片加入屏保轮播。

## 回滚

- 壁纸：恢复为默认壁纸
- 外观：改回浅色/系统默认强调色即可
- 本项目不修改任何系统文件，无需卸载
